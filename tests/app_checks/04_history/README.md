# 점검이력 탭 및 엑셀 내보내기 (`04_history`)

- **대분류**: 점검이력 탭
- **엑셀 범위**: `69릴리즈` 시트 38행 ~ 47행
- **pytest 마커**: `app_check`, `app_history`

## 1. 테스트 대상 및 기대 동작 명세
1. **점검 이력 리스트 및 최근점검일시 (Row 38~39)**
   - 1번 점검 일시와 상단 최근점검일시의 동일성 확인
   - 점검 이력 테이블/리스트 정상 렌더링 확인
2. **점검 상세 내역 (Row 40~44)**
   - 이력 리스트 중 특정 행 클릭 시 상세 내역 확장
   - 사용자 정보 및 점검 결과 데이터 일치 확인
   - 각 점검 항목(안전/취약) 결과 일치 확인
   - '전체 열기', '전체 닫기' 버튼 기능 확인
   - 각 행의 토글 아코디언 버튼 기능 확인
3. **엑셀 내보내기 (Row 45~47)**
   - 엑셀 아이콘 클릭 시 파일 저장 경로 및 파일명 지정 다이얼로그 확인
   - 저장 완료 시 `"점검 내역을 엑셀 파일로 저장했습니다."` 팝업 확인
   - 생성된 엑셀 보고서의 점검 항목 데이터와 실제 UI 점검 내용 정합성 검증

## 2. 테스트 파일 구성
- `test_history_list.py`: 이력 리스트 렌더링, 상세 내역 토글, 전체 열기/닫기
- `test_excel_export.py`: 엑셀 저장 대화상자 조작, 완료 팝업 및 실제 생성된 엑셀 파싱 정합성 검증
