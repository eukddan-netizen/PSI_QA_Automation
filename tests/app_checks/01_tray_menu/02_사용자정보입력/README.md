# 02. 사용자 정보 입력 (`tray_02`)

- **대분류**: 트레이 아이콘
- **중분류**: 사용자 정보 입력
- **엑셀 범위**: 12행 ~ 15행 (`2_0001` ~ `2_0004`)
- **실행 명령**: `.\run tray 2` (또는 `pytest -m tray_02 -s`) — *트레이 우클릭 메뉴 제어 시 관리자 권한 콘솔 필요*

- 별도 웹 관리자 접속 없이, **트레이 아이콘 우클릭 > '사용자 정보 입력'**을 직접 클릭하여 팝업되는 웹뷰 입력 창을 대상으로 검증합니다.

## 테스트 명세
| 행 | TC_ID | 조건 | 액션 | 기대 결과 |
| :-: | :-: | :--- | :--- | :--- |
| 12 | 2_0001 | 웹뷰 진입 | 트레이 아이콘 > 사용자 정보 입력 | 사용자 입력 웹뷰 출력 |
| 13 | 2_0002 | 필수 값 미입력 | 1. 사번 미입력 2. 이름 미입력 3. 둘 다 미입력 | `"사번 or 이름을 입력하세요."` alert 팝업 |
| 14 | 2_0003 | 잘못된 값 입력 | 인사 등록 되지 않은 값(9999 / 홍길동) 입력 후 저장 | `"등록된 인사 정보와 일치하지 않습니다"` alert 팝업 |
| 15 | 2_0004 | 정상 등록 | 등록되어 있는 인사 정보(0014 / KYC) 입력 후 저장 | `"정상 등록되었습니다"` alert 팝업 |
