# 트레이 아이콘 (`01_tray_menu`)

- **대분류**: 트레이 아이콘
- **엑셀 범위**: `2026.06` 시트 9행 ~ 19행
- **pytest 마커**: `app_check`, `app_tray` (전체) / `tray_01` ~ `tray_06` (중분류별 실행)

## 중분류 폴더 구조 (Row 9~19)

| 번호 | 중분류 폴더 | 마커 | 엑셀 행 | TC_ID | 실행 명령 |
| :-: | :--- | :---: | :-: | :-: | :--- |
| **01** | `01_내PC보안점검/` | `tray_01` | 9~11 | `1_0001`~`1_0003` | `.\run tray 1` |
| **02** | `02_사용자정보입력/` | `tray_02` | 12~15 | `2_0001`~`2_0004` | `.\run tray 2` |
| **03** | `03_프로그램목록재확인/` | `tray_03` | 16 | `3_0001` | `.\run tray 3` *(관리자 권한)* |
| **04** | `04_폰트목록재확인/` | `tray_04` | 17 | `4_0001` | `.\run tray 4` *(관리자 권한)* |
| **05** | `05_에이전트업데이트실행/` | `tray_05` | 18 | `5_0001` | `.\run tray 5` *(B/논의 요망)* |
| **06** | `06_정보확인/` | `tray_06` | 19 | `6_0001` | `.\run tray 6` *(관리자 권한)* |

## 빠른 실행 예시

```powershell
# 트레이 아이콘 대분류 전체(중분류 1~6) 순차 실행
.\run tray

# 특정 중분류 단위 실행 (예: 1번 내PC보안점검 / 2번 사용자 정보 입력)
.\run tray 1
.\run tray 2

# 여러 중분류 연속/선택 실행
.\run tray 1-2
.\run tray 1,3,6
```
