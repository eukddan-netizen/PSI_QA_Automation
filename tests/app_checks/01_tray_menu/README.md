# 트레이 아이콘 메뉴 및 에이전트 연동 (`01_tray_menu`)

- **대분류**: 트레이 아이콘
- **엑셀 범위**: `69릴리즈` 시트 9행 ~ 19행
- **pytest 마커**: `app_check`, `app_tray`

## 1. 테스트 대상 및 기대 동작 명세
1. **내PC보안점검 메뉴 (Row 9~11)**
   - 보안점검 실행 중 트레이 메뉴 클릭 시: 무반응(중복 실행 방지)
   - 인사 UI 출력 ON 상태: 사용자 정보 입력 웹뷰 출력
   - 인사 UI 출력 OFF 상태: 보안점검 메인 화면 출력
2. **사용자 정보 입력 웹뷰 (Row 12~15)**
   - 웹뷰 진입 확인
   - 필수 값 미입력 (사번 미입력, 이름 미입력, 둘 다 미입력): `"사번 or 이름을 입력하세요."` alert 팝업 확인
   - 잘못된 값 입력: 인사 미등록 값 입력 후 저장 시 `"등록된 인사 정보와 일치하지 않습니다"` alert 팝업 확인
   - 정상 등록: 등록된 인사 정보 값 입력 후 저장 시 `"정상 등록되었습니다"` alert 팝업 확인
3. **프로그램 목록 재확인 (Row 16)**
   - 클릭 시 `"소프트웨어 목록 재검사를 성공적으로 수행하였습니다."` 팝업 출력 및 `taPRSAgentv5` 로그 확인
4. **폰트 목록 재확인 (Row 17)**
   - 클릭 시 `"폰트 목록 재검사를 성공적으로 수행하였습니다."` 팝업 출력 및 `taPRSAgentv5` 로그 확인
5. **에이전트 업데이트 실행 (Row 18)**
   - 클릭 시 에이전트 모듈 업데이트 성공(빌드번호) 로그 확인
6. **정보 확인 (Row 19)**
   - 클릭 시 보유 제품명 및 서버, 사용자 IP 팝업 출력 확인

## 2. 테스트 파일 구성
- `test_tray_menu.py`: 트레이 우클릭 메뉴 항목 클릭, 팝업 출력 및 로그 검증
- `test_user_info_form.py`: 사용자 정보 입력 웹뷰의 유효성 검증(Validation) 및 alert 팝업
