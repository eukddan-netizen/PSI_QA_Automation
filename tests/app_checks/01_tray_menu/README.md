# 트레이 아이콘 (`01_tray_menu`)

- **대분류**: 트레이 아이콘
- **pytest 마커**: `app_check`, `app_tray` (전체) / `tray_01` ~ `tray_07` (중분류별 실행)

## 중분류 폴더 구조

| 번호 | 중분류 폴더 | 마커 | TC_ID | 실행 명령 |
| :-: | :--- | :---: | :-: | :--- |
| **01** | `01_내PC보안점검/` | `tray_01` | `1_0001`~`1_0003` | `.\run tray 1` |
| **02** | `02_패치현황/` | `tray_02` | `2_0001` | `.\run tray 2` *(관리자 권한)* |
| **03** | `03_사용자정보입력/` | `tray_03` | `3_0001`~`3_0004` | `.\run tray 3` *(관리자 권한)* |
| **04** | `04_프로그램목록재확인/` | `tray_04` | `4_0001` | `.\run tray 4` *(관리자 권한)* |
| **05** | `05_폰트목록재확인/` | `tray_05` | `5_0001` | `.\run tray 5` *(관리자 권한)* |
| **06** | `06_에이전트업데이트실행/` | `tray_06` | `6_0001` | `.\run tray 6` *(B/논의 요망)* |
| **07** | `07_정보확인/` | `tray_07` | `7_0001` | `.\run tray 7` *(관리자 권한)* |

## 빠른 실행 예시

```powershell
# 트레이 아이콘 대분류 전체(중분류 1~7) 순차 실행
.\run tray

# 특정 중분류 단위 실행 (예: 1번 내PC보안점검 / 2번 패치 현황 / 3번 사용자 정보 입력)
.\run tray 1
.\run tray 2
.\run tray 3

# 여러 중분류 연속/선택 실행
.\run tray 1-2
.\run tray 1,2,7
```
