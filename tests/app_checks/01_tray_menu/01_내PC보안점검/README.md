# 01. 내PC보안점검 (`tray_01`)

- **대분류**: 트레이 아이콘
- **중분류**: 내PC보안점검
- **엑셀 범위**: 9행 ~ 11행 (`1_0001` ~ `1_0003`)
- **실행 명령**: `.\run tray 1` (또는 `pytest -m tray_01 -s`)

## 테스트 명세
| 행 | TC_ID | 조건 | 액션 | 기대 결과 |
| :-: | :-: | :--- | :--- | :--- |
| 9 | 1_0001 | 보안점검 실행중 | 트레이 아이콘 > 내PC보안점검 | 무반응 (중복 창 미생성) |
| 10 | 1_0002 | 인사 UI 출력 OFF | 트레이 아이콘 > 내PC보안점검 | 프로그램 창 정상 노출 |
| 11 | 1_0003 | 인사 UI 출력 ON | 트레이 아이콘 > 내PC보안점검 | 보안점검 메인 화면 및 인사 UI 출력 |
