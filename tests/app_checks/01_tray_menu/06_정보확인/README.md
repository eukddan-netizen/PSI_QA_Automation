# 06. 정보 확인 (`tray_06`)

- **대분류**: 트레이 아이콘
- **중분류**: 정보 확인
- **엑셀 범위**: 19행 (`6_0001`)
- **실행 명령**: `.\run tray 6` (또는 `pytest -m tray_06 -s`) — *트레이 우클릭 메뉴 제어 시 관리자 권한 콘솔 필요*

## 테스트 명세
| 행 | TC_ID | 조건 | 액션 | 기대 결과 |
| :-: | :-: | :--- | :--- | :--- |
| 19 | 6_0001 | 정상 동작 | 트레이 아이콘 > 정보 확인 | 보유 제품명 및 서버, 사용자 IP 팝업 출력 |

## 팝업 출력 예시 및 검증 항목
```text
1차 팝업 (TA-STR)
관리서버 : 58.127.84.36        <- TA-STR 고정 관리서버 IP(58.127.84.36) 정합성 일치 검증
사용자 IP : 192.168.2.28       <- 현재 PC의 ipconfig IPv4 주소와 일치 검증
[확인] 버튼 클릭

2차 팝업 (TA-PRS)
관리서버 : 192.168.4.151       <- TA-PRS 고정 관리서버 IP(192.168.4.151) 정합성 일치 검증
사용자 IP : 192.168.2.28       <- 현재 PC의 ipconfig IPv4 주소와 일치 검증
[확인] 버튼 클릭
```
- 제품 빌드 버전 정보는 검증 대상에서 제외하고, 각 제품(STR, PRS)의 **고정 관리서버 IP 주소**와 `ipconfig` 명령을 통해 실시간 조회한 **현재 PC의 사용자 IPv4 주소**가 일치하는지 정밀 검증한 뒤, 각각의 `[확인]` 버튼을 클릭하여 모든 팝업을 정상 닫기 처리합니다.
