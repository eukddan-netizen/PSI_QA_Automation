# 02. 패치 현황 (`tray_02`)

- **대분류**: 트레이 아이콘
- **중분류**: 패치 현황
- **TC_ID**: `2_0001`
- **실행 명령**: `.\run tray 2` (또는 `pytest -m tray_02 -s`) — *트레이 우클릭 메뉴 제어 시 관리자 권한 콘솔 필요*

## 검증 절차
1. 트레이 아이콘 우클릭 > **패치 현황** 좌클릭 후 출력되는 팝업(`TA 공지`)에서 아래 두 테이블 정보를 수집하고 `[확인]`으로 닫기:
   - **권고패치 현황**: 종류별 `전체`, `설치`, `패치율` 및 `총계`
   - **설치 패치 목록**: `종류`, `이름`, `발표일` *(권고 패치만 표출됨)*
2. `https://192.168.4.151` 관리자 로그인 > `/patch` 접속 후 `ipconfig` 기반 현재 PC의 IP로 사용자 검색
3. 검색된 사용자 행의 `패치 정보` 컬럼에서 **권고** 개수(`설치/전체개`) 확인 및 클릭 (`/patch/client` 상세 이동)
4. `/patch/client` 테이블과 각 설치 완료 패치의 패치 정보 모달(`발표일`)을 순회 수집한 뒤, 트레이 팝업의 `권고패치 현황`(종류별 전체/설치/패치율, 총계) 및 `설치 패치 목록`(종류, 이름, 발표일)과 1:1 정합성 검증
