# 03. 사용자 정보 (`main_03`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 사용자 정보
- **엑셀 범위**: 25행 ~ 26행
- **실행 명령**: `.\run.ps1 main 3` (또는 `pytest -m main_03 -s`)

## 테스트 명세
| 행 | 항목 | 조건 | 액션 | 기대 결과 |
| :-: | :--- | :--- | :--- | :--- |
| 25 | 사용자 정보 정합성 | 메인 화면 진입 | 현재 PC IP(ipconfig) 추출 후 관리자 웹(/pcsafe) 사용자 정보와 비교 | OS 정보, 부서명, 사용자명, 사용자 IP가 서버 등록 정보와 일치 |
| 26 | 최근점검일시 갱신 | 점검 완료 후 탭 이동 | 점검 완료 후 대기하다가 타 탭 이동 또는 창 종료 수행 | 점검 시작 시점이 아닌 탭 이동(보고서 전송) 시점 기준으로 최근점검일시가 갱신되고 서버와 일치 |

## 상세 검증 절차

### 1. [Row 25] 사용자 정보 정합성 검증
1. `ipconfig` 및 네트워크 인터페이스를 통해 현재 로컬 PC의 IPv4 주소 목록 추출
2. 관리자 웹 콘솔(`https://192.168.4.151/pcsafe`) 접속 후 해당 IP로 사용자 검색
3. 서버의 사용자 행에서 부서(`t1`), 사용자명(`KYC`), OS(`11 Pro 64bit 25H2`), 단말 IP(`192.168.2.28`) 수집
4. 보안점검 프로그램 실행 후 우측 상단 '사용자 정보' 카드의 각 항목 텍스트 파싱
5. 클라이언트 앱에 표기된 정보가 서버 데이터 및 실제 로컬 단말 환경과 정확히 일치하는지 비교 검증

### 2. [Row 26] 탭 이동/종료 시점 기준 최근점검일시 갱신 검증
1. 메인 화면에서 이전 최근점검일시(`prev_time`) 확인
2. `▶ 점검 시작` 버튼을 클릭하여 점검 진행 및 `점검결과` 탭으로 전환 확인
3. 결과 탭 진입 후 일정 시간 대기 (시작 시점 반영이 아님을 증명)
4. `메인` 탭으로 이동 액션을 수행하고, 해당 액션 시점(`action_time`) 기록
5. 메인 화면으로 돌아왔을 때 표출되는 `최근점검일시`(`new_time`)가 이전 일시와 다르게 갱신되었는지 확인
6. 갱신된 일시가 탭 이동을 트리거한 시점(`action_time`) 기준으로 반영(±15초 이내)되었는지 확인
7. 관리자 웹(`/pcsafe`)을 새로고침하여 서버에 기록된 '최종 점검일'도 앱과 동일한 시각으로 전송 완료되었는지 크로스 검증
