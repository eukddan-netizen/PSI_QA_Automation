## 검증 절차
1. **점검결과 탭 세부 데이터 수집**:
   - `점검결과` 탭으로 이동하여 5개 분야 21개 항목의 상태(`안전`/`취약`) 수집
   - 분야별 `(안전 항목수 / 전체 항목수) * 100` 계산 (1의 자리 정수)
2. **레이더 차트 꼭짓점 좌표 계산 및 Hover**:
   - 레이더 차트 영역 크기 및 중심점(`cx, cy`) 계산
   - 5개 축 각도(-90°, -18°, 54°, 126°, 198°) 및 점수 비례 반지름($r = R_{max} \times \frac{\text{score}}{100}$)에 따른 꼭짓점 좌표 산출
   - 마우스 커서를 꼭짓점 위치로 이동(`Hover`)하여 툴팁 표출 유도
3. **툴팁 값 정합성 검증**:
   - UIA Text 요소로 표출된 툴팁 점수 취득
   - 계산된 기대 점수와 툴팁 점수가 오차 1점 이내로 일치하는지 비교 검증
