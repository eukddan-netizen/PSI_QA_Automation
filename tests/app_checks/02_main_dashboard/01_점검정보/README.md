# 01. 점검 정보 (`main_01`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 점검 정보
- **엑셀 범위**: 20행 ~ 23행
- **실행 명령**: `.\run main 1` (또는 `pytest -m main_01 -s`)

## 테스트 명세
| 행 | 항목 | 조건 (관리자 웹 `/pcsafeManage` → `t1` 정책) | 액션 | 기대 결과 |
| :-: | :--- | :--- | :--- | :--- |
| 20 | 대기 상태 | 1번 항목 점수 2점, 2번 항목 점수 0점 변경 후 수정·정책 적용 | 트레이로 `내PC보안점검` 실행 | 회색 방패(`대기`), `"취약점 검사 필요"` / `"검사를 진행해 주십시오"` 문구 및 서버 `안전기준점수` 연동 |
| 21 | 안전 상태 | `안전 기준 점수` 10점 변경 후 수정·정책 적용 | 트레이로 실행 및 보안점검 완료 후 메인 탭 확인 | 점검점수 >= 10점, 파란 방패(`양호`), `안전기준점수 10점`, 우상단 `X` 클릭 시 팝업 없이 즉시 종료 |
| 22 | 취약 상태 및 종료 경고 | `안전 기준 점수` 100점 변경 후 수정·정책 적용 | 트레이로 실행 및 보안점검 완료 후 메인 탭 확인, `X` 클릭 | 점검점수 < 100점, 빨간 방패(`위험`), `안전기준점수 100점`, `X` 클릭 시 사용 제한 경고 팝업(`취소`/`종료`) 노출 |
| 23 | 점검 시작 버튼 | 정상 대기/완료 상태 | 메인 화면에서 `▶ 점검 시작` 클릭 | `점검` 진행 후 `점검결과` 탭으로 자동 이동 및 결과 요약 표시 |
