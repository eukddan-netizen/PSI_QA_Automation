# 01. 점검 정보 (`main_01`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 점검 정보
- **엑셀 범위**: 20행 ~ 23행
- **실행 명령**: `.\run main 1` (또는 `pytest -m main_01 -s`)

## 테스트 명세
| 행 | 항목 | 조건 | 액션 | 기대 결과 |
| :-: | :--- | :--- | :--- | :--- |
| 20 | 최근 점검 이력 없음 | 최근 점검 이력 없음 | 메인 화면 진입 | 방패 아이콘 "대기", "취약점 검사 필요, 검사를 진행해 주십시오." 문구 노출 |
| 21 | 최근 점검 이력 있음 (양호) | 점수 >= 안전기준점수 | 메인 화면 진입 | 방패 아이콘 "양호" 상태 표시 |
| 22 | 최근 점검 이력 있음 (취약) | 점수 < 안전기준점수 | 메인 화면 진입 및 창 닫기(X) 클릭 | 방패 아이콘 "취약" 상태 표시 및 기준점수 미만 시 PC 사용 제한 확인 팝업 출력 |
| 23 | 점검 시작 버튼 | - | '점검 시작' 버튼 클릭 | 점검 진행 탭으로 자동 이동 및 검사 개시 |
