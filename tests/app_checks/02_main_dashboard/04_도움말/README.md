# 04. 도움말 (`main_04`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 도움말
- **엑셀 범위**: 27행 ~ 31행
- **실행 명령**: `.\run main 4` (또는 `pytest -m main_04 -s`)

## 테스트 개요
메인 화면 우측의 '도움말 안내' 카드를 클릭하여 호출되는 소개 및 점검항목 조치방법 웹뷰 모달 창의 기능과 53개 보안점검 항목 콘텐츠의 무결성을 전수 검증합니다. (이미지는 검증 대상에서 제외)
