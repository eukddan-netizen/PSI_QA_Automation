# 메인 대시보드 및 상호작용 UI (`02_main_dashboard`)

- **대분류**: 보안점검 메인 탭
- **엑셀 범위**: `69릴리즈` 시트 20행 ~ 34행
- **pytest 마커**: `app_check`, `app_main`

## 1. 테스트 대상 및 기대 동작 명세
1. **좌측 점검 정보 (Row 20~23)**
   - 최근 점검 이력 없음: 방패 아이콘 "대기", '취약점 검사 필요, 검사를 진행해 주십시오.' 문구
   - 최근 점검 이력 있음 (점수 >= 안전기준점수): 방패 아이콘 "양호"
   - 최근 점검 이력 있음 (점수 < 안전기준점수): 방패 아이콘 "취약" 및 창 닫기(X) 시 기준점수 미만 PC 사용 제한 팝업 출력
   - '점검 시작' 버튼 클릭: 점검 탭으로 이동 및 검사 개시
2. **PC보안지표 (Row 24)**
   - 각 안전지수 항목에 마우스 hover 시 해당 지표 점수 툴팁 출력
3. **사용자 정보 (Row 25~26)**
   - 최초 실행 시 최근점검일시 `0000-00-00 00:00:00`
   - 점검 완료 후 결과 전송 시각으로 최근점검일시 자동 갱신
4. **도움말 안내 (Row 27~31)**
   - 도움말 안내 클릭 시 소개 웹뷰 모달 출력
   - 햄버거 아이콘 클릭 시 nav_bar 열림/닫힘
   - 언어 en 설정 시 네비게이션 타이틀 영문 변경
   - 아코디언 토글 클릭 시 콘텐츠 여닫힘 및 깨짐/오탈자 없음 확인
5. **암호 안전성 검사 (Row 32)**
   - 암호 안전성 검사 버튼 클릭 시 안전성 항목 검증 모달 출력
6. **지난 검사내역 (Row 33~34)**
   - 검사 내역 항목에 hover 시 당시 점수 출력
   - 특정 검사 내역 클릭 시 '점검이력' 탭의 해당 상세 내역으로 즉시 이동

## 2. 테스트 파일 구성
- `test_dashboard_ui.py`: 방패 상태, 기준 점수 미만 종료 경고 팝업, 지표 hover 툴팁, 사용자 정보 반영
- `test_help_modal.py`: 도움말 모달(햄버거, 영문 언어, 토글 아코디언)
- `test_password_modal.py`: 암호 안전성 검사 모달
