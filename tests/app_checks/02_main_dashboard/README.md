# 보안점검 메인 탭 (`02_main_dashboard`)

- **대분류**: 보안점검 메인 탭
- **pytest 마커**: `app_check`, `app_main` (전체) / `main_01` ~ `main_06` (중분류별 실행)

## 중분류 폴더 구조

| 번호 | 중분류 폴더 | 마커 | 엑셀 범위 | 내용 요약 | 실행 명령 |
| :-: | :--- | :--- | :---: | :--- | :--- |
| **01** | `01_점검정보/` | `main_01` | Row 20~23 | 방패 상태(대기/양호/취약), 미만 종료 경고 팝업, 점검 시작 이동 | `.\run main 1` |
| **02** | `02_PC보안지표/` | `main_02` | Row 24 | 각 안전지수 항목 hover 시 해당 지표 점수 툴팁 표시 | `.\run main 2` |
| **03** | `03_사용자정보/` | `main_03` | Row 25~26 | 최초 실행 시 0000-00-00, 점검 완료 후 최근점검일시 자동 갱신 | `.\run main 3` |
| **04** | `04_도움말/` | `main_04` | Row 27~31 | 소개 웹뷰 모달, 햄버거 토글, 영문 언어 변경, 아코디언/콘텐츠 무결성 | `.\run main 4` |
| **05** | `05_암호안전성검사/` | `main_05` | Row 32 | 암호 안전성 검사 모달 팝업 및 항목 검증 | `.\run main 5` |
| **06** | `06_지난검사내역/` | `main_06` | Row 33~34 | hover 시 당시 점수 툴팁 출력 및 클릭 시 점검이력 상세 이동 | `.\run main 6` |

## 빠른 실행 예시

```powershell
# 보안점검 메인 탭 대분류 전체(중분류 1~6) 순차 실행
.\run main

# 특정 중분류 단위 실행 (예: 1번 점검 정보 / 4번 도움말)
.\run main 1
.\run main 4

# 여러 중분류 연속/선택 실행
.\run main 1-3
.\run main 1,4,5

# 중분류 목록 보기
.\run main list
```
