# 06. 지난 검사내역 (`main_06`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 지난 검사내역
- **엑셀 범위**: 33행 ~ 34행
- **실행 명령**: `.\run main 6` (또는 `pytest -m main_06 -s`)

## 테스트 명세
| 행 | 항목 | 조건 | 액션 | 기대 결과 |
| :-: | :--- | :--- | :--- | :--- |
| 33 | 지난 점검 점수 툴팁 | 메인 화면에 지난 검사내역 표시 | 특정 검사내역 행에 Hover | 당시 점수 툴팁 노출 |
| 34 | 점검이력 상세 이동 | 메인 화면에 지난 검사내역 표시 | 특정 검사내역 항목 클릭 | '점검이력' 탭으로 전환 및 해당 일자의 상세 내역으로 즉시 이동 |
