# 06. 지난 검사내역 (`main_06`)

- **대분류**: 보안점검 메인 탭
- **중분류**: 지난 검사내역
- **엑셀 범위**: 33행 ~ 34행
- **실행 명령**: `.\run main 6` (또는 `pytest -m main_06 -s`)

## 테스트 개요
메인 대시보드 우측 하단의 '지난 검사내역' 차트에서 표출된 막대 그래프(과거 -> 최신 순 정렬, 0~6개 가변 대응)를 대상으로 각 막대 호버 시 점수 표출 검증과, 막대 각각을 순차 클릭하여 '점검이력' 상세 내역 진입 및 점검이력 목록 점검일시와의 1:1 역순 매핑 정합성을 전수 검증합니다. 점검 기록이 없거나 6회 미만인 PC 환경에서도 동적으로 완벽하게 대응합니다.

## 테스트 명세
| 행 | 함수명 | 항목 | 검증 세부 내용 | 기대 결과 |
| :-: | :--- | :--- | :--- | :--- |
| 33 | `test_row33_past_history_bar_count_and_hover_scores` | 지난 점검 점수 툴팁/호버 검증 (0~6개 가변) | 막대 그래프 탐색 및 각 막대 호버 시 점수 표출 확인 | - 0개 ~ 최대 6개의 막대 그래프 존재 감지 (우측으로 갈수록 최근 내역)<br>- 점검 이력 없는 경우 0개 정상 확인 후 스킵<br>- 존재하는 각 막대 호버 시 당시 점수(0~100) 정상 표출 확인 |
| 34 | `test_row34_all_six_bars_click_match_history_tab_records` | 막대 그래프 클릭 및 점검이력 일시 1:1 역순 매핑 검증 (가변) | 막대를 각각 클릭하여 점검 상세 내역 이동 및 점검이력 레코드 일시/점수 1:1 대조 | - 막대가 0개면 점검이력 탭도 0건인지 교차 확인<br>- 막대가 N개(1~6)인 경우:<br>  - `막대 i` $\leftrightarrow$ `점검이력 [(N-1)-i]번 행` 일시/점수 일치 (마지막 우측 막대 = 점검이력 1번 최신 행)<br>  - 각 상세 화면의 점수와 호버 점수 100% 일치 확인 |

## 관련 페이지 객체
- [MainPage](file:///d:/psi_automation/pages/main_page.py):
  - `get_past_history_bars()`: 6개 막대 바 UIA 요소 추출 (좌->우 정렬)
  - `hover_and_get_past_history_score(bar_index)`: 막대 호버 점수 반환
  - `click_past_history_bar(bar_index)`: 막대 클릭하여 상세 이동
  - `get_history_detail_info()`: 점검 상세 내역 화면 점수 및 점검일시 파싱
  - `get_history_tab_records(limit)`: 점검이력 탭 목록 행 파싱
