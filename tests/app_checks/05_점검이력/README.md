# 점검이력 탭 및 엑셀 내보내기 (`05_history`)

- **대분류**: 점검이력 탭
- **엑셀 범위**: `69릴리즈` 시트 38행 ~ 47행
- **pytest 마커**: `app_check`, `app_history`

## 0. 선행 전제 조건 (`conftest.py`)
1. `history_test_session`: 프로그램 실행 → `설정 > 정보` 탭 버전 수집 → 점검 전 이력 건수 확인 → `▶ 점검 시작` 후 `점검결과` 탭 데이터(요약, 전 항목, 샘플 상세설명) 수집 → `메인` 탭 복귀(보고서 서버 전송) → `점검이력` 탭 이동(100건 초과 시 재실행 후 최근 100건 유지 검증 포함)
2. `server_history_data`: 관리자 웹(`/pcsafeManage`, `/pcsafe`)에서 사용자 부서 적용 정책 안전기준점수 및 사용자 정보 수집 후 자동화 전용 크롬 창 즉시 종료

## 1. 테스트 대상 및 기대 동작 명세
1. **최근점검일시 및 안전기준점수 (`test_history_list.py`)**
   - 점검이력 상단 `최근점검일시`, 1번 행 `점검 일시`, 메인 탭 `최근점검일시`, 서버 최종 점검일 일치 검증
   - 우측 상단 `안전기준점수`와 관리자 웹(`/pcsafeManage`) 사용자 부서 적용 정책의 안전기준점수 일치 검증
2. **점검이력 최대 100건 제한 (`test_history_list.py`)**
   - 점검이력 리스트 최대 100건 제한 검증 (100건 상태에서 점검 실행 후 일시적으로 초과하더라도 보안점검 재실행 시 최근 100건으로 유지되는지 검증)
3. **점검 상세 내역 진입 및 사용자 정보/결과 정합성 (`test_history_list.py`)**
   - 가장 최근 점검이력 클릭 → `점검 상세 내역` 화면 이동
   - 사용자 정보(점검일시, IP, 사용자명, 부서명, OS, 바이러스백신, 버전)와 메인/서버/OS/`설정 > 정보` 버전 일치 검증
   - 상세 내역 요약 및 전 항목 결과/항목명/상세설명이 현재 `점검결과` 탭과 일치하는지 검증
4. **전체 열기/전체 닫기 및 개별 토글 (`test_history_list.py`)**
   - `전체 열기` / `전체 닫기` 토글 버튼 전환 및 전체/개별 행 아코디언 펼침·접힘 검증
5. **엑셀 내보내기 (`test_excel_export.py`)**
   - 우측 상단 엑셀 아이콘 클릭 → `#32770` 저장 다이얼로그에서 바탕화면(`내PC보안점검_YYYYMMDD_HHMMSS.xlsx`) 저장 → `"점검 내역을 엑셀 파일로 저장했습니다."` 완료 팝업 확인
   - 생성된 엑셀 파일을 `openpyxl`로 열어 파일명, 버전, 사용자 정보, 점검결과 및 점수의 데이터와 단위(`개`/`점`), 각 보안점검 항목명과 상세설명 정합성 검증
   - *(참고: `#32770` 저장 다이얼로그 제어 시 Windows UIPI 제약으로 관리자 권한 PowerShell 실행 필요)*

## 2. 테스트 파일 구성
- `conftest.py`: 점검 선행 실행, 100건 초과 시 재실행 처리 및 서버 정책/사용자 정보 조회 Fixture
- `test_history_list.py`: 최근점검일시, 안전기준점수, 100건 제한, 상세 내역 사용자/결과 정합성, 전체·개별 토글 검증
- `test_excel_export.py`: 엑셀 저장 대화상자 조작, 완료 팝업 및 실제 생성된 엑셀 파싱 정합성 검증
