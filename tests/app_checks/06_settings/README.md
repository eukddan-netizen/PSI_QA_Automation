# 설정 탭 (일반/외형/정보) (`06_settings`)

- **대분류**: 설정 탭
- **엑셀 범위**: `69릴리즈` 시트 59행 ~ 65행
- **pytest 마커**: `app_check`, `app_settings`

## 1. 테스트 대상 및 기대 동작 명세
1. **일반 설정 (Row 59~60)**
   - 점검 후 결과 화면 자동 이동 체크 해제 시: 점검 완료 시 바로 이동하지 않고 `"결과 화면으로 이동"` 확인 팝업 출력
   - 팝업에서 버튼 클릭 시 결과 탭으로 정상 이동 및 일시 반영
2. **외형 설정 (Row 61~64)**
   - 라이트 모드 선택 시 전체 UI 라이트 테마 전환
   - 라이트 모드 상태에서 다른 탭 및 기능 무결성 유지 검증
   - 최초 실행 및 로딩 화면 시 다크모드가 디폴트인지 검증
3. **정보 (Row 65)**
   - 프로그램 현재 빌드/버전 정보 텍스트 정상 출력 확인

## 2. 테스트 파일 구성
- `test_general_options.py`: 결과 화면 자동 이동 옵션 해제에 따른 확인 팝업 분기 테스트
- `test_theme_mode.py`: 다크/라이트 테마 전환 및 디폴트 테마 무결성 검증
