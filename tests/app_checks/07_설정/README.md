# 설정 탭 (일반/외형/정보) (`07_settings`)

- **대분류**: 설정 탭
- **엑셀 범위**: `69릴리즈` 시트 59행 ~ 65행
- **pytest 마커**: `app_check`, `app_settings`

## 1. 테스트 대상 및 기대 동작 명세
1. **일반 설정 (Row 59~60)**
   - 기본 상태: `'점검 후 결과 화면으로 자동 이동'` 옵션 체크(`True`) 상태 확인
   - 체크 해제 후 메인 탭 / 점검 탭에서 점검 진행 시 바로 결과 탭으로 이동하지 않고 `'점검이 완료되었습니다. 결과 화면으로 이동합니다.'` 확인 팝업 출력
   - 팝업에서 `'결과 화면으로 이동'` 버튼 클릭 시 `'점검결과'` 탭으로 정상 이동 및 결과 렌더링 확인 (종료 시 체크 상태 원복)
2. **외형 설정 (Row 61~64)**
   - 최초 실행 및 로딩 화면 시 다크 모드가 디폴트이고 `'시스템 테마'`가 현재 Windows OS 테마와 일치하는지 검증
   - `'라이트 모드'` 전환 및 프로그램 재실행 후 영속성 검증
   - 라이트 모드 상태에서 전체 6개 탭(`메인`, `점검`, `점검결과`, `점검이력`, `PC정리`, `설정`)의 라이트 배경 적용 및 핵심 UI/모달/점검 기능 무결성 검증 (종료 시 `'다크 모드'` 원복)
3. **정보 (Row 65)**
   - `'설정 > 정보'` 탭에 표기된 `'앱 버전'`과 관리자 웹(`https://192.168.4.151/manageAgent`) `'최근 등록 정보'` 내 `taKeeper.exe` 버전 일치 검증

## 2. 테스트 파일 구성
- `test_general_options.py`: 자동 이동 옵션 기본값 확인 및 해제 시 확인 팝업/이동 분기 테스트 (`메인`, `점검` 탭 파라미터화)
- `test_theme_mode.py`: 기본 다크 모드 검증, 라이트 모드 전환/영속성/전 탭 무결성 검증, 서버 `/manageAgent` `taKeeper.exe` 버전 대조 검증
