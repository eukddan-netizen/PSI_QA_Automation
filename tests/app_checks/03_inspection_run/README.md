# 점검 진행 탭 (`03_inspection_run`)

- **대분류**: 점검 탭
- **엑셀 범위**: `69릴리즈` 시트 35행 ~ 37행
- **pytest 마커**: `app_check`, `app_inspection`

## 1. 테스트 대상 및 기대 동작 명세
1. **점검 시작 및 실시간 피드백 (Row 35~36)**
   - 점검 시작 시 점검 항목 결과 및 경과 시간 실시간 반영
   - 프로그레스바(progressbar) 진행률 100% 완료 후 점검결과 탭으로 자동 전환
2. **사용자 정보 일치 (Row 37)**
   - 점검 진행 중 표시되는 사용자 정보가 서버/메인 탭 데이터와 동일한지 확인

## 2. 테스트 파일 구성
- `test_inspection_progress.py`: 점검 진행 애니메이션/진행률/사용자정보 동기화 및 결과 탭 전환 검증
