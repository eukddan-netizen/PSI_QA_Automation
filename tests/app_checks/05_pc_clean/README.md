# PC정리 탭 및 시스템 정보 연동 (`05_pc_clean`)

- **대분류**: PC정리 탭
- **엑셀 범위**: `69릴리즈` 시트 48행 ~ 58행
- **pytest 마커**: `app_check`, `app_clean`

## 1. 테스트 대상 및 기대 동작 명세
1. **시스템 정보 연동 (Row 48~50)**
   - OS VERSION: Windows `winver` 버전 정보와 UI 텍스트 일치 확인
   - ANTIVIRUS: 실시간 보호 ON/OFF 변경 후 보안점검 새로고침 아이콘 클릭 시 UI 동기화 확인
   - FIREWALL: Windows 방화벽 ON/OFF 변경 후 보안점검 새로고침 아이콘 클릭 시 UI 동기화 확인
2. **내 PC 정리 (Row 51~58)**
   - 휴지통 비우기: 정리 진행 후 확인 팝업 및 실제 휴지통 비워짐 확인
   - 윈도우 임시 파일: `%temp%` 항목 삭제 팝업 및 실제 디렉터리 내 파일 삭제 확인
   - 캐시 및 성능 데이터: Chrome 및 Edge의 `Cache_Data` 전후 비교 검증
   - 기록 및 탐색 데이터: 브라우저 방문 기록 삭제 검증
   - 저장소/세션/쿠키/미디어 데이터 정리 동작 검증

## 2. 테스트 파일 구성
- `test_system_status.py`: OS 버전, 백신 및 방화벽 상태 실시간 연동 및 새로고침
- `test_file_cleaner.py`: 휴지통, 임시폴더, 브라우저 캐시 삭제 UI 및 실제 OS 파일 삭제 정합성
