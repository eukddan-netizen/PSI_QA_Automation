# 점검결과 탭 공통 UI 및 정렬 (`07_result_common`)

- **대분류**: 점검결과 탭
- **엑셀 범위**: `69릴리즈` 시트 66행 ~ 71행
- **pytest 마커**: `app_check`, `app_result`

## 1. 테스트 대상 및 기대 동작 명세
1. **방패 아이콘 및 점수 (Row 66)**
   - 점검 완료 후 안전기준점수 기준에 맞는 방패 아이콘 출력 및 총점 점수 무결성 검증
2. **사용자 정보 및 요약 카운트 (Row 67~68)**
   - 메인/서버 데이터와 일치하는 사용자 정보 확인
   - 서버 설정 항목관리 정책과 일치하는 전체/안전/취약/점검불가 개수 요약과 하위 리스트의 합계 일치 검증
3. **테이블 헤더 정렬 (Row 69~71)**
   - 1열 헤더 `"번호"` 2회 클릭: 번호 오름차순/내림차순 정렬 검증
   - 2열 헤더 `"점검 항목"` 2회 클릭: 항목명 가나다순 정렬 검증
   - 3열 헤더 `"결과"` 2회 클릭: 안전/취약 상태별 정렬 검증

## 2. 테스트 파일 구성
- `test_result_summary.py`: 상단 종합 방패, 총점 점수 및 요약 카운트(전체/안전/취약/불가) 무결성
- `test_table_sorting.py`: 결과 테이블 컬럼 헤더(번호, 점검항목, 결과) 클릭 정렬 기능 검증
