# 점검 탭 (`03_inspection_tab`)

- **대분류**: 점검 탭
- **엑셀 범위**: `69릴리즈` 시트 38행 ~ 40행 (`TC 13_0001`, `13_0002`, `14_0001`)
- **pytest 마커**: `app_check`, `app_inspection`

## 1. 테스트 대상 및 기대 동작 명세
1. **사용자 정보 일치 (Row 40 / TC `14_0001`, 우선 실행)**
   - 점검 탭에 표시되는 사용자 정보(OS 정보, 부서명, 사용자명, 사용자 IP, 최근점검일시)가 메인 탭 데이터와 동일한지 확인
2. **점검 시작 및 실시간 피드백 / 결과 탭 전환 (Row 38~39 / TC `13_0001`, `13_0002`)**
   - 점검 탭 내 `▶ 점검 시작` 버튼 클릭 시 점검 항목 결과, 진행률(`%`) 및 진행 시간 실시간 반영
   - 프로그레스바 진행률 100% 완료 후 `점검결과` 탭으로 자동 전환

## 2. 테스트 파일 구성
- `test_inspection_progress.py`:
  1. `test_inspection_tab_user_info_matches_main`: 메인 탭 ↔ 점검 탭 사용자 정보 일치 검증
  2. `test_inspection_start_realtime_and_auto_navigation`: 점검 시작 클릭, 실시간 진행률/시간 반영 및 결과 탭 자동 전환 검증
