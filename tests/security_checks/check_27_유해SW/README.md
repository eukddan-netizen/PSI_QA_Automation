# 27. 유해 SW 설치 여부 점검 (`check_27_유해SW`)

- **점검 번호**: 27번
- **점검 제목**: 27. 유해 SW 설치 여부 점검
- **앱 UI 키워드**: `유해 SW 설치 여부`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버에서 유해 SW 정책을 등록하고 대상 프로그램 설치 및 언인스톨 모달을 제어해야 함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check27`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 유해 SW 설치 여부 점검
- [유해 sw 정책 x] 안전 및 해로운 소프트웨어가 설치되어 있지 않습니다.
- 취약 및 해로운 소프트웨어가 설치되어 있습니다. + 해당 sw명 출력
- [유해 sw 존재(1개)] 해당 sw uninstall 모달 출력
- [유해 sw 1개 존재 및 해당 sw uninstall 모달 출력 상태] 안전 및 해로운 소프트웨어가 설치되어 있지 않습니다.
- 취약 및 해로운 소프트웨어가 설치되어 있습니다. + 해당 sw명 출력
- [유해 sw 존재(2개)] 리스트 상 첫 번째 sw uninstall 모달 출력
- [유해 sw 2개 존재 및 해당 sw uninstall 모달 출력 상태] 첫 번째 sw 제거 후 두 번째 sw uninstall 모달 출력
- [두 번째 sw uninstall 모달 출력 상태] 안전 및 해로운 소프트웨어가 설치되어 있지 않습니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (유해 sw 정책 x) 점검 진행
- 점검 대상 pc의 특정 sw 유해 정책 설정(1개) 후 점검 진행
- (유해 sw 1개 존재 및 해당 sw uninstall 모달 출력 상태) uninstall 진행
- 점검 대상 pc의 특정 sw 유해 정책 설정(2개) 후 점검 진행
- (유해 sw 2개 존재 및 해당 sw uninstall 모달 출력 상태) uninstall 진행
- (두 번째 sw uninstall 모달 출력 상태) uninstall 진행

## 3. 조치 시 기대 동작
- **조치 진행(해당 sw 선택 후 제거)** → 해당 sw uninstall 모달 출력
- **조치 진행(해당 sw들 선택 후 제거)** → 리스트 상 첫 번째 sw uninstall 모달 출력
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
