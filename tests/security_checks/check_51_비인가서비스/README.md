## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 비인가 서비스 항목 전체 삭제>PSI 재부팅>점검 진행
- XblGameSave 항목 등록>PSI 재부팅>점검 진행
- (XblGameSave 비인가 서비스 항목 등록 상태) 서비스>Xbox Live 게임 저장>시작유형: 수동>적용(A)>시작(S) >점검 진행
- 서비스>Xbox Live 게임 저장>서비스 중지>점검 진행
- (XblGameSave 비인가 서비스 항목 등록 상태) XboxNetApiSvc 추가 등록>PSI 재부팅>점검 진행
- (XblGameSave, XboxNetApiSvc 비인가 서비스 항목 등록 상태) 서비스>Xbox Live 네트워킹 서비스>시작유형: 수동>적용(A)>시작(S)>점검 진행
- (Xbox Live 네트워킹 서비스 실행 중 상태) 서비스>Xbox Live 게임 저장>시작유형: 수동>적용(A)>시작(S)>점검 진행
- 서비스>Xbox Live 게임 저장, Xbox Live 네트워킹 서비스>서비스 중지>점검 진행
