- **점검 제목**: 26. Google Chrome 최신 업데이트 점검
- **앱 UI 키워드**: `Google Chrome 최신 업데이트`

- **분류 근거**: 기존 Chrome 삭제(필요 시 재부팅) 및 특정 구버전 Chrome MSI 설치 환경 구성이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check26`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: Google Chrome 최신 업데이트 점검
- [크롬 설치 x] 안전 및 Chrome이 설치되지 않았습니다.
- [크롬 미설치 상태(설치된 경우 삭제 진행)(삭제 안되는 경우 재부팅 후 삭제)] 취약 및 Chrome이 최신 버전이 아닙니다. 현재 버전과 최신 버전 데이터 출력
- [크롬 구버전 설치 상태] 안전 및 현재 최신 버전 데이터 출력
- [크롬 구버전 설치 상태] 안전 및 현재 최신 버전 데이터 출력

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (크롬 설치 x) 점검 진행
- (크롬 미설치 상태(설치된 경우 삭제 진행)(삭제 안되는 경우 재부팅 후 삭제)) 비고 링크를 통해 특정 구버전 크롬 msi 다운 및 설치 후 점검 진행(너무 오래된 버전 x)
- (크롬 구버전 설치 상태) 크롬>점 세 개>도움말>Chrome 정보>(자동 업데이트) 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → 안전 및 현재 최신 버전 데이터 출력
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
