# 44. 인가된 DNS 서버 사용 점검 (`check_44_인가된DNS`)

- **점검 번호**: 44번
- **점검 제목**: 44. 인가된 DNS 서버 사용 점검
- **앱 UI 키워드**: `인가된 DNS 서버 사용`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버에 인가 DNS 주소(1개 또는 2개)를 등록하고 PC 네트워크 어댑터 DNS 설정과 대조해야 함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check44`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 인가된 DNS 서버 사용 점검
- 안전 및 관리자가 아무런 DNS 서버도 설정하지 않았습니다.
- [등록된 DNS와 테스트 PC의 DNS가 다른 상태] 취약 및 관리자가 설정한 DNS 서버와 기본 DNS 서버가 다릅니다. 관리자 설정: 5.5.5.5 (등록한 DNS 값) 현재 설정: 8.8.8.8 (테스트 PC 설정 값)
- 안전 및 관리자가 설정한 DNS 서버를 기본 DNS 서버로 사용 중입니다.
- 취약 및 컴퓨터의 DNS 서버 중 관리자가 설정하지 않은 DNS 서버가 있습니다. 다음 중 하나의 주소로 설정해 주세요. - 168.126.63.1 - 5.5.5.5
- 안전 및 PC의 DNS 서버가 서버에서 지정한 DNS 서버로 설정되어 있습니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 관리 DNS 모두 삭제>psi 재부팅>점검 진행
- (등록된 DNS와 테스트 PC의 DNS가 다른 상태) DNS 하나 등록(5.5.5.5)>psi 재부팅>점검 진행
- (등록된 DNS: 5.5.5.5 테스트 PC 기본DNS: 8.8.8.8) 테스트 PC 대체 DNS에 5.5.5.5 추가 후 점검 진행
- 테스트 PC 기본 DNS 5.5.5.5 변경 후 점검 진행
- DNS 두 개 등록(5.5.5.5, 168.126.63.1)>psi 재부팅 >테스트 PC 기본 DNS: 5.5.5.5>점검 진행
- (등록된 DNS: 5.5.5.5, 168.126.63.1) 테스트 PC 기본 DNS: 5.5.5.5 테스트 PC 대체 DNS: 8.8.8.8 점검 진행
- 테스트 PC 기본 DNS: 5.5.5.5 테스트 PC 대체 DNS: 168.126.63.1 점검 진행
- 테스트 PC 기본 DNS: 168.126.63.1 테스트 PC 대체 DNS: 5.5.5.5 점검 진행

## 3. 조치 시 기대 동작
- 별도 자동 조치 버튼 시나리오 없음 (OS 상태 변경 후 재점검 시 상태 전환 및 점수 가감 확인)
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
