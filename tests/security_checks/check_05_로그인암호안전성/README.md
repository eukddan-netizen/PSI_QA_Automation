# 05. 로그인 암호 안전성 점검 (`check_05_로그인암호안전성`)

- **점검 번호**: 5번
- **점검 제목**: 5. 로그인 암호 안전성 점검
- **앱 UI 키워드**: `로그인 암호 안전성`
- **자동화 난이도**: Tier B (외부 프로그램 설치 또는 PowerShell/권한/재부팅 환경 구성 필요)
- **분류 근거**: 실제 Windows 로그인 암호 변경 및 앱 내 암호 입력/조치 모달의 다중 조합 상호작용이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check05`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 로그인 암호 안전성 점검
- [강력한 암호로 변경] 안전 및 현재 강력한 암호를 사용하고 있습니다.
- [취약 암호로 변경 + 조치 창에서 변경 시도] 변경불가
- 변경불가 및 입력할 수 없는 문자가 포함되어 있습니다.
- 현재 암호가 올바르지 않습니다.
- [상세 내용 문구] 암호의 길이가 너무 짧습니다. 암호는 대문자, 소문자, 숫자, 특수문자 중 세 가지 이상 조합하여 9자 이상이어야 합니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (강력한 암호로 변경) 3가지 조합(소,대,특) + 9자 이상: qweQWE!@#
- 3가지 조합(소,대,숫) + 9자 이상: qweQWE123
- 3가지 조합(소,특,숫) + 9자 이상: qwe!@#123
- 3가지 조합(대,특,숫) + 9자 이상: QWE!@#123
- (취약 암호로 변경 + 조치 창에서 변경 시도) 3가지 조합 + 9자 미만: Qwe12312
- 2가지 조합(소문자,대문자) + 9자 이상: Qweqweqwe
- 2가지 조합(소문자,특수문자) + 9자 이상: qweqwe!@#
- 2가지 조합(소문자,숫자) + 9자 이상: qweqwe123
- 2가지 조합(대문자,특수문자) + 9자 이상: QWEQWE!@#
- 2가지 조합(대문자,숫자) + 9자 이상: QWEQWE123
- 2가지 조합(특수문자,숫자) + 9자 이상: !@#!@#123
- 2가지 조합(소문자,대문자) + 9자 미만: QWEqweqw
- 1가지 조합(소문자) + 9자 이상: qweqweqwe
- 1가지 조합(대문자) + 9자 이상: QWEQWEQWE
- 1가지 조합(특수문자) + 9자 이상: !@#!@#!@#
- 1가지 조합(숫자) + 9자 이상: 123123123
- 1가지 조합(숫자) + 9자 미만: 12312312
- 한글 입력
- 현재 암호를 올바르게 입력하지 않고 변경 시도

- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
