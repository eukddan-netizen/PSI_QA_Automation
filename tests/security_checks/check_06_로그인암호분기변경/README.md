# 06. 로그인 암호 분기별 변경 여부 점검 (`check_06_로그인암호분기변경`)

- **점검 번호**: 6번
- **점검 제목**: 6. 로그인 암호 분기별 변경 여부 점검
- **앱 UI 키워드**: `로그인 암호 분기별 변경`
- **자동화 난이도**: Tier B (외부 프로그램 설치 또는 PowerShell/권한/재부팅 환경 구성 필요)
- **분류 근거**: 시스템 날짜를 3개월 초과로 수동 변경하고 점검 시 뜨는 윈도우 로그인 암호 모달을 제어해야 함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check06`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 로그인 암호 분기별 변경 여부 점검
- [안전] 암호를 변경한지 3개월이 되지 않았습니다.
- 윈도우 로그인 암호 모달 출력
- 이 계정의 비밀번호가 만료되었습니다. 팝업 출력
- 비밀번호가 일치하지 않습니다.
- 5번 항목 점검 불가 / 6번 항목 취약(비밀번호 변경 3개월 초과)
- 현재 암호가 올바르지 않습니다.
- 새로운 암호가 너무 짧거나, 암호 기록 정책, 복잡성 요구 사항 등 다른 암호 정책에 위배됩니다.
- 조치 완료
- 윈도우 로그인 암호 모달 출력
- 비밀번호가 일치하지 않습니다.
- 5,6번 항목 안전

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (안전) 점검 진행
- 설정>날짜 및 시간 변경: 3개월 초과 날짜로 수동 설정 후 점검
- 암호 모달에서 현재 비밀번호 입력 후 확인 버튼 클릭
- 암호 모달에서 현재 비밀번호 아닌 값 입력 후 확인 버튼 클릭
- 건너뛰기 클릭
- 암호 모달에서 현재 비밀번호 아닌 값 입력 후 확인 버튼 클릭
- 건너뛰기 클릭
- 재점검 클릭 후 암호 모달에서 현재 비밀번호 입력 후 확인 버튼 클릭

## 3. 조치 시 기대 동작
- **조치 진행 후 현재 비밀번호 일치하지 않는 값 입력 후 변경** → 현재 암호가 올바르지 않습니다.
- **조치 진행 후 현재 비밀번호 입력 후 새 암호도 동일 값 입력 후 변경 시도** → 새로운 암호가 너무 짧거나, 암호 기록 정책, 복잡성 요구 사항 등 다른 암호 정책에 위배됩니다.
- **조치 진행 후 현재 비밀번호 입력 후 새 암호는 다른 값 입력 후 변경 시도** → 조치 완료
- **조치 후 재점검 시도** → 윈도우 로그인 암호 모달 출력
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
