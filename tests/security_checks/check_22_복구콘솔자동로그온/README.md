# 22. 복구콘솔에서 자동로그온 금지 설정 여부 점검 (`check_22_복구콘솔자동로그온`)

- **점검 번호**: 22번
- **점검 제목**: 22. 복구콘솔에서 자동로그온 금지 설정 여부 점검
- **앱 UI 키워드**: `복구 콘솔에서 자동 로그온`
- **자동화 난이도**: Tier A (레지스트리/net 명령/Windows 기본 설정으로 완전 자동화 가능)
- **분류 근거**: HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Setup\RecoveryConsole의 SecurityLevel 레지스트리로 제어 가능함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check22`, `tier_a`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 복구콘솔에서 자동로그온 금지 설정 여부 점검
- 취약 및 복구 콘솔의 보안 수준이 낮음으로 설정되어 있습니다.
- [취약] 안전 및 복구콘솔: 자동 관리 로그온 허용 -> '사용 안 함'으로 설정 됨
- 취약 및 복구 콘솔의 보안 수준이 낮음으로 설정되어 있습니다.
- [securitylevel: 0 이외의 값] 안전 및 securitylevel: 0
- 취약 및 복구 콘솔의 보안 수준이 낮음으로 설정되어 있습니다.
- [복구콘솔: 자동 관리 로그온 허용 -> '사용' + securitylevel: 0 이외의 값] 안전 및 복구콘솔: 자동 관리 로그온 허용 -> '사용 안 함' + securitylevel: 0으로 설정 됨

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 그룹 정책 편집 > 컴퓨터 구성 > Windows 설정 > 보안설정 > 로컬정책 > 보안옵션 > 복구콘솔: 자동 관리 로그온 허용 -> '사용' 후 점검 진행
- Reg HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Setup\RecoveryConsole의 REG_DWORD securitylevel의 값: 0 이외의 값으로 설정 후 점검 진행
- 복구콘솔: 자동 관리 로그온 허용 -> '사용' + securitylevel: 0 이외의 값 설정 후 점검 진행

- **조치 진행** → 안전 및 securitylevel: 0
- **조치 진행** → 안전 및 복구콘솔: 자동 관리 로그온 허용 -> '사용 안 함' + securitylevel: 0으로 설정 됨
