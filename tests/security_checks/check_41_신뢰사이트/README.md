# 41. 신뢰 사이트 등록 여부 점검 (`check_41_신뢰사이트`)

- **점검 번호**: 41번
- **점검 제목**: 41. 신뢰 사이트 등록 여부 점검
- **앱 UI 키워드**: `신뢰 사이트 등록 여부`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버에 테스트용 신뢰 사이트 URL을 등록하고 에이전트를 재시작해야 함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check41`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 신뢰 사이트 등록 여부 점검
- [안전] 취약 및 관리자가 설정한 신뢰할 수 있는 사이트 중 등록되지 않은 사이트가 있습니다.
- [취약] 안전 및 관리자가 설정한 신뢰할 수 있는 사이트가 모두 등록되어 있습니다. 인터넷 옵션>보안>신뢰할 수 있는 사이트>사이트>웹 사이트에 등록되어 있는 지 확인 HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains에 해당 사이트 url 등록되어 있는 지 확인
- 안전 및 관리자가 설정한 신뢰할 수 있는 사이트가 모두 등록되어 있습니다. HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains에 해당 사이트 url 등록되어 있는 지 확인

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (안전) 서버에 테스트용 신뢰 사이트 등록 후 psi 재부팅 후 점검 진행
- 서버에 테스트용 신뢰 사이트 등록 후 인터넷 옵션>보안>신뢰할 수 있는 사이트>사이트>웹 사이트에 해당 url 등록 psi 재부팅 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → 안전 및 관리자가 설정한 신뢰할 수 있는 사이트가 모두 등록되어 있습니다. 인터넷 옵션>보안>신뢰할 수 있는 사이트>사이트>웹 사이트에 등록되어 있는 지 확인 HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains에 해당 사이트 url 등록되어 있는 지 확인
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
