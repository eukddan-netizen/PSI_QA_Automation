# 30. 미사용 계정 존재 여부 점검 (`check_30_미사용계정`)

- **점검 번호**: 30번
- **점검 제목**: 30. 미사용 계정 존재 여부 점검
- **앱 UI 키워드**: `미사용 계정 존재 여부`
- **자동화 난이도**: Tier A (레지스트리/net 명령/Windows 기본 설정으로 완전 자동화 가능)
- **분류 근거**: net user 명령으로 비활성(/active:no) 로컬 계정을 생성·삭제하여 자동화 가능함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check30`, `tier_a`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 미사용 계정 존재 여부 점검
- [미사용 계정 x] 안전 및 비활성 상태의 사용자 계정이 없습니다.
- 취약 및 비활성 상태의 사용자 계정이 있습니다. + 해당 계정명 출력
- [추가한 계정 '사용 안함' 상태] 안전 및 비활성 상태의 사용자 계정이 없습니다.
- [추가한 계정 '사용' 상태] 취약 및 비활성 상태의 사용자 계정이 있습니다. + 해당 계정명 출력 컴퓨터 관리>로컬 사용자 및 그룹>사용자>해당 계정 '사용 안함' 체크 상태
- [취약] 안전 및 컴퓨터 관리>로컬 사용자 및 그룹>사용자에서 해당 계정 삭제 확인
- 취약 및 비활성 상태의 사용자 계정이 있습니다. + 해당 계정명 출력(2개)
- [미사용 계정 2개] 안전 및 컴퓨터 관리>로컬 사용자 및 그룹>사용자에서 해당 계정들 삭제 확인

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (미사용 계정 x) 점검 진행
- 1. 다른 사용자>계정 추가 2. 컴퓨터 관리>로컬 사용자 및 그룹>사용자>해당 계정 '사용 안함' 체크 -> 점검 진행
- (추가한 계정 '사용 안함' 상태) 1. 컴퓨터 관리>로컬 사용자 및 그룹>사용자>해당 계정 '사용 안함' uncheck -> 점검 진행
- 1. 다른 사용자>계정 추가(2개) 2. 컴퓨터 관리>로컬 사용자 및 그룹>사용자>해당 계정들 '사용 안함' 체크 -> 점검 진행

## 3. 조치 시 기대 동작
- **1. 보안점검 17번 항목 '메인 계정 외 기타 계정 존재 여부 점검' 항목 조치 진행 -> 점검 진행** → 취약 및 비활성 상태의 사용자 계정이 있습니다. + 해당 계정명 출력 컴퓨터 관리>로컬 사용자 및 그룹>사용자>해당 계정 '사용 안함' 체크 상태
- **조치 진행(해당 계정 선택 후 확인)** → 안전 및 컴퓨터 관리>로컬 사용자 및 그룹>사용자에서 해당 계정 삭제 확인
- **조치 진행(해당 계정들 선택 후 확인)** → 안전 및 컴퓨터 관리>로컬 사용자 및 그룹>사용자에서 해당 계정들 삭제 확인
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
