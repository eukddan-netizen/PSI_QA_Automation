- [한컴오피스 + MS office 설치된 상태] 취약 및 Word 2024 설치되어 있음 문구
- [MS office 설치된 상태] 안전 및 한컴오피스 한글, Microsoft Word, Adobe Acrobat이 설치되지 않았습니다.
