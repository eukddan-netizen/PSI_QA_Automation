# 25. 멀티 윈도우 OS 사용 여부 점검 (`check_25_멀티윈도우OS`)

- **점검 번호**: 25번
- **점검 제목**: 25. 멀티 윈도우 OS 사용 여부 점검
- **앱 UI 키워드**: `멀티 윈도우 OS 사용 여부`
- **자동화 난이도**: Tier A (레지스트리/net 명령/Windows 기본 설정으로 완전 자동화 가능)
- **분류 근거**: bcdedit /copy 및 /delete 명령으로 테스트용 부팅 항목을 추가·삭제하여 자동화 가능함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check25`, `tier_a`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 멀티 윈도우 OS 사용 여부 점검
- [bcdedit 결과: 2개 (Windows Boot Manager, Windosw 11)] 안전 및 컴퓨터에 하나의 운영체제만 설치되어 있습니다.
- 취약 및 컴퓨터에 두 개 이상의 운영체제가 설치되어 있습니다. Bcdedit 결과: 3개
- [bcdedit 결과: 3개] 안전 및 bcdedit 결과: 2개

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (bcdedit 결과: 2개 (Windows Boot Manager, Windosw 11)) 점검 진행
- bcdedit /copy {current} /d "테스트용 OS" -> 현재 os copy 후 등록
- (bcdedit 결과: 3개) 시스템 구성>부팅>"테스트용 OS" 삭제>적용 후 점검 진행

## 3. 조치 시 기대 동작
- 별도 자동 조치 버튼 시나리오 없음 (OS 상태 변경 후 재점검 시 상태 전환 및 점수 가감 확인)
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
