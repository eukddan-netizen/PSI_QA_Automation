- **구현 상태**: `skeleton`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 최근 암호 기억 기능 사용 여부 점검
- 취약 및 현재 암호 정책은 이전 암호를 기억하지 않습니다. 이로 인해 최근 암호를 반복 사용할 수 있어 보안성이 낮아질 수 있습니다.
- [최근 암호 기억: 0개 상태] 안전 및 이전 암호를 기억하여 최근 암호 재사용을 방지하는 정책을 사용하므로 보안성이 향상됩니다. 현재 시스템은 마지막 1개의 암호를 기억합니다. 로컬 보안 정책>계정 정책>암호 정책>최근 암호 기억: 1개
- 안전 및 현재 시스템이 마지막 몇 개(~24개)의 암호를 기억하는지 출력

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 로컬 보안 정책>계정 정책>암호 정책>최근 암호 기억: 0개로 설정 후 점검 진행
- 로컬 보안 정책>계정 정책>암호 정책>최근 암호 기억: 0 이외의 값 설정(최대 24개) 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → 안전 및 이전 암호를 기억하여 최근 암호 재사용을 방지하는 정책을 사용하므로 보안성이 향상됩니다. 현재 시스템은 마지막 1개의 암호를 기억합니다. 로컬 보안 정책>계정 정책>암호 정책>최근 암호 기억: 1개
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
