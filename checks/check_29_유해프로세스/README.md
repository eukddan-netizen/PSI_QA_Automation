# 29. 유해 프로세스 실행 여부 점검 (`check_29_유해프로세스`)

- **점검 번호**: 29번
- **점검 제목**: 29. 유해 프로세스 실행 여부 점검
- **앱 UI 키워드**: `유해 프로세스 실행 여부`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버에서 유해 프로세스(CalculatorApp.exe, notepad.exe)를 등록하고 에이전트를 재시작해야 함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check29`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 유해 프로세스 실행 여부 점검
- [실행 중인 유해 프로세스 x] 안전 및 유해 프로세스가 없습니다.
- 취약 및 유해 프로세스가 동작 중입니다. + 해당 프로세스명 출력(CalculatorApp.exe)
- [CalculatorApp.exe 유해 등록 상태 및 CalculatorApp.exe 실행 상태] 안전 및 해당 프로세스 종료
- [CalculatorApp.exe 유해 등록 상태] 취약 및 유해 프로세스가 동작 중입니다. + 해당 프로세스명 출력(CalculatorApp.exe, notepad.exe)
- [CalculatorApp.exe, notepad.exe 유해 등록 상태 및 CalculatorApp.exe, notepad.exe 실행 상태] 안전 및 해당 프로세스들 종료

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (실행 중인 유해 프로세스 x) 점검 진행
- CalculatorApp.exe 유해 프로세스 등록>psi 재부팅>계산기 실행>점검 진행
- (CalculatorApp.exe 유해 등록 상태) notepad.exe 유해 프로세스 등록>psi 재부팅>메모장, 계산기 실행>점검 진행

## 3. 조치 시 기대 동작
- **조치 진행(종료할 프로세스(계산기) 선택 후 확인)** → 안전 및 해당 프로세스 종료
- **조치 진행(종료할 프로세스(계산기, 메모장) 선택 후 확인)** → 안전 및 해당 프로세스들 종료
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
