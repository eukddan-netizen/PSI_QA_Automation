# 38. 암호 사용 최대/최소 기간 설정 여부 점검 (`check_38_암호사용최대기간`)

- **점검 번호**: 38번
- **점검 제목**: 38. 암호 사용 최대/최소 기간 설정 여부 점검
- **앱 UI 키워드**: `암호 사용 최대/최소 기간 설정`
- **자동화 난이도**: Tier A (레지스트리/net 명령/Windows 기본 설정으로 완전 자동화 가능)
- **분류 근거**: net accounts /maxpwage 명령으로 최대 암호 사용 기간(무기한 vs 90일)을 제어하여 자동화 가능함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check38`, `tier_a`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 암호 사용 최대/최소 기간 설정 여부 점검
- 취약 및 현재 암호 정책은 비밀번호가 만료 없이 무기한 사용되도록 허용합니다. 이 설정은 정기적인 암호 변경을 강제하지 않아 보안성을 낮출 수 있습니다.
- [최대 암호 사용 기간: 0일] 안전 및 최대 암호 사용 기간: 90일
- 안전 및 현재 암호가 며칠(~999)마다 만료되는지 출력

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 로컬 보안 정책>계정 정책>암호 정책>최대 암호 사용 기간: 0일로 설정 후 점검 진행
- 로컬 보안 정책>계정 정책>암호 정책>최대 암호 사용 기간: 0일 이외의 값(최대 999일) 입력 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → 안전 및 최대 암호 사용 기간: 90일
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
