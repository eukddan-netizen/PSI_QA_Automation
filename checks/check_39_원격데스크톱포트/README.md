- **점검 제목**: 39. 원격 데스크톱 포트 설정 점검
- **앱 UI 키워드**: `원격 데스크톱 포트 설정`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버의 원격 데스크톱 지정 포트 설정 유무에 따라 판정 및 조치 가능 여부가 달라져 서버 정책 연동이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check39`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 원격 데스크톱 포트 설정 점검
- [관리자가 원격 데스크톱 포트 지정하지 않은 상태] 안전 및 원격 데스크톱 서비스가 기본 포트 번호가 아닌 xxxx 포트를 사용 중입니다. 이는 보안에 도움이 됩니다. 설정한 포트 번호까지 출력됨
- 관리자가 원격 데스크톱 포트를 지정하지 않아 조치할 수 없습니다.
- 취약 및 원격 데스크톱 서비스가 현재 기본 포트 번호인 3389를 사용 중입니다. 보안을 위해 비표준 포트로 변경하는 것이 좋습니다.
- [관리자가 원격 데스크톱 포트 지정한 상태(1234)] 취약 및 관리자가 지정한 원격 데스크톱 포트(1234)를 사용해야합니다.
- 안전 및 원격 데스크톱 포트로 관리자가 지정한 포트(1234)를 사용 중입니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (관리자가 원격 데스크톱 포트 지정하지 않은 상태) HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp의 PortNumber: 3389(d3d)이외의 값 설정 후 점검 진행
- HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp의 PortNumber: 3389(d3d) 설정 후 점검 진행
- (관리자가 원격 데스크톱 포트 지정한 상태(1234)) HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp의 PortNumber: 1234이외의 값 설정 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → 관리자가 원격 데스크톱 포트를 지정하지 않아 조치할 수 없습니다.
- **취약 상태에서 조치 진행** → 안전 및 원격 데스크톱 포트로 관리자가 지정한 포트(1234)를 사용 중입니다.
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
