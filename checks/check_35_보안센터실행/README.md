# 35. 보안센터 실행 여부 점검 (`check_35_보안센터실행`)

- **점검 번호**: 35번
- **점검 제목**: 35. 보안센터 실행 여부 점검
- **앱 UI 키워드**: `보안센터 실행 여부`
- **자동화 난이도**: Tier B (외부 프로그램 설치 또는 PowerShell/권한/재부팅 환경 구성 필요)
- **분류 근거**: wscsvc 서비스 레지스트리 키 소유자(Owner)/권한(ACL) 탈취 및 Start 값 변경 후 OS 재부팅이 필수임
- **구현 상태**: `skeleton`
- **pytest 마커**: `check35`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 보안센터 실행 여부 점검
- 안전 및 윈도우 보안센터 서비스가 실행 중입니다.
- 취약 및 윈도우 보안센터 서비스가 실행 중이지 않습니다.
- "(자동 /지연된 시작)으로 변경하지 못함" 모달 출력
- 안전 및 윈도우 보안센터 서비스가 실행 중입니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- 점검 진행
- HKLM\SYSTEM\CurrentControlSet\Services\wscsvc 경로 이동 wscsvc 키(폴더) 우클릭 -> 권한(P)... 선택 하단의 고급(V) 버튼 클릭 상단 소유자(Owner) 옆의 변경 클릭 -> Administrators 입력 후 확인 Administrators 그룹에 모든 권한 - 허용 체크 후 적용 Start 값 4로 변경 후 재부팅 -> 점검 진행
- HKLM\SYSTEM\CurrentControlSet\Services\wscsvc 경로 이동 wscsvc 키(폴더) 우클릭 -> 권한(P)... 선택 하단의 고급(V) 버튼 클릭 상단 소유자(Owner) 옆의 변경 클릭 -> Administrators 입력 후 확인 Administrators 그룹에 모든 권한 - 허용 체크 후 적용 Start 값 2로 변경 후 재부팅 -> 점검 진행

## 3. 조치 시 기대 동작
- **조치 진행** → "(자동 /지연된 시작)으로 변경하지 못함" 모달 출력
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
