- **점검 번호**: 3번
- **점검 제목**: 3. OS, MS 최신 보안 패치 점검
- **앱 UI 키워드**: `최신 보안 패치 점검`
- **자동화 난이도**: Tier B (외부 프로그램 설치 또는 PowerShell/권한/재부팅 환경 구성 필요)
- **분류 근거**: Windows 및 MS Office 보안 패치 롤백과 서버 설치 정책 변경 환경 구성이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check03`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: OS, MS 최신 보안 패치 점검
- [최신 상태] 안전 및 시스템이 최신 상태입니다. Windows 또는 MS Office의 새 업데이트가 없습니다.
- [취약 상태] 취약

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (최신 상태) 점검 진행
- (취약 상태) ms 보안패치 롤백 진행 완료 후 다시 권고 상태에서 검사 진행(설치 정책 off 해야 함)

## 3. 조치 시 기대 동작
- 별도 자동 조치 버튼 시나리오 없음 (OS 상태 변경 후 재점검 시 상태 전환 및 점수 가감 확인)
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
