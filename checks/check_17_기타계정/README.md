# 17. 메인 계정 외 기타 계정 존재 여부 점검 (`check_17_기타계정`)

- **점검 번호**: 17번
- **점검 제목**: 17. 메인 계정 외 기타 계정 존재 여부 점검
- **앱 UI 키워드**: `메인 계정 외 기타 계정`
- **자동화 난이도**: Tier A (레지스트리/net 명령/Windows 기본 설정으로 완전 자동화 가능)
- **분류 근거**: net user 명령으로 테스트용 로컬 계정을 추가·삭제하여 외부 도구 없이 자동화 가능함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check17`, `tier_a`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 메인 계정 외 기타 계정 존재 여부 점검
- [메인 계정만 존재] 안전 및 현재 계정 외에 활성화된 다른 계정이 없습니다.
- 취약 및 활성화 된 기타 계정 정보 출력
- [계정 하나 추가 상태] 안전 및 현재 계정 외에 활성화된 다른 계정이 없습니다. 윈도우>기타 사용자> 추가한 계정 사라졌는지 확인
- 취약 및 활성화 된 기타 계정 정보 출력
- [계정 두 개 추가 상태] 안전 및 현재 계정 외에 활성화된 다른 계정이 없습니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (메인 계정만 존재) 점검 진행
- 윈도우>기타 사용자>계정 추가 후 점검 진행
- 윈도우>기타 사용자>계정 추가 * 2 후 점검 진행

## 3. 조치 시 기대 동작
- **조치 버튼 클릭>계정 선택>확인** → 안전 및 현재 계정 외에 활성화된 다른 계정이 없습니다. 윈도우>기타 사용자> 추가한 계정 사라졌는지 확인
- **조치 버튼 클릭>전체 선택>확인** → 안전 및 현재 계정 외에 활성화된 다른 계정이 없습니다.
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
