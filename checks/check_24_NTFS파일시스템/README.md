# 24. 파일 시스템 NTFS 사용 여부 점검 (`check_24_NTFS파일시스템`)

- **점검 번호**: 24번
- **점검 제목**: 24. 파일 시스템 NTFS 사용 여부 점검
- **앱 UI 키워드**: `파일 시스템 NTFS 사용 여부`
- **자동화 난이도**: Tier B (외부 프로그램 설치 또는 PowerShell/권한/재부팅 환경 구성 필요)
- **분류 근거**: 10GB 가상 하드 디스크(VHD) 파일을 생성·초기화하고 FAT32/NTFS 볼륨으로 포맷하는 디스크 환경 작업이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check24`, `tier_b`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 파일 시스템 NTFS 사용 여부 점검
- [NTFS만 존재] 안전 및 모든 고정 디스크 드라이브가 NTFS 파일 시스템을 사용 중입니다.
- 취약 및 고정 디스크 드라이브 중 NTFS 파일 시스템이 아닌 것이 있습니다.(해당 디스크 경로 출력)
- [FAT32 존재 상태] 안전 및 모든 고정 디스크 드라이브가 NTFS 파일 시스템을 사용 중입니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (NTFS만 존재) 점검 진행
- 1. 'windows' 마우스 우클릭>디스크 관리>동작>VHD 만들기>C 드라이브로 위치 지정(파일명: fat32_test.vhd)>10GB>확인 2. 디스크 우클릭>디스크 초기화>MBR>검은 영역 우클릭>새 단순 볼륨>FAT 32 선택 -> 점검 진행
- (FAT32 존재 상태) 해당 디스크 우클릭>포맷>NTFS 변경 후 점검

## 3. 조치 시 기대 동작
- 별도 자동 조치 버튼 시나리오 없음 (OS 상태 변경 후 재점검 시 상태 전환 및 점수 가감 확인)
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
