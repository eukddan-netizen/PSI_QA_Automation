- **점검 번호**: 52번
- **점검 제목**: 52. 비인가 메신저 사용 여부 점검
- **앱 UI 키워드**: `비인가 메신저 사용 여부`
- **자동화 난이도**: Tier C (관리 서버 정책 등록, 하드웨어/OS 버전, 대량 데이터 등 별도 환경 필요)
- **분류 근거**: 관리 서버에 비인가 메신저(카카오톡 등) 정책을 등록하고 실제 메신저 설치·언인스톨러 실행이 필요함
- **구현 상태**: `skeleton`
- **pytest 마커**: `check52`, `tier_c`

## 1. 점검 대상 및 판정 기준 / 안내 문구
- **점검 대상**: 비인가 메신저 사용 여부 점검
- [등록된 비인가 메신저 x] 안전 및 허용되지 않은 메신저 프로그램이 없습니다.
- [카카오톡 미설치 상태] 안전 및 허용되지 않은 메신저 프로그램이 없습니다.
- [카카오톡 비인가 메신저 등록 상태] 취약 및 허용되지 않은 메신저 프로그램이 설치되어 있습니다. 카카오톡
- [카카오톡 취약 상태] 카카오톡 uninstaller 모달 출력
- [카카오톡 uninstaller 모달 출력 상태] 안전 및 허용되지 않은 메신저 프로그램이 없습니다.

## 2. 상태를 만드는 방법 (OS / 환경 설정)
- (등록된 비인가 메신저 x) 점검 진행
- (카카오톡 미설치 상태) 카카오톡 비인가 메신저로 등록>PSI 재부팅>점검 진행
- (카카오톡 비인가 메신저 등록 상태) 카카오톡 설치>점검 진행
- (카카오톡 uninstaller 모달 출력 상태) 제거 진행
- (카카오톡 취약 상태) 설정>앱>설치된 앱>카카오톡 제거>점검 진행

## 3. 조치 시 기대 동작
- **조치>카카오톡 선택>확인** → 카카오톡 uninstaller 모달 출력
- 공통 사항: 취약 상태에서 안전 상태로 전환 시 상단 취약 건수 감소 및 서버 설정 점수 가감 일치 확인
